# Arc mainnet 与 Solana 功能对齐目标

更新：2026-09-26。本文是本轮实施范围与验收合同；“目标”不等于已经上线。

## 范围

在现有 Benny Wallet 内完成双链账户、资产、估值、收款、发送、历史、通知和自定义代币同步。沿用现有 Send → Receive → Swap 入口、网络选择和资产角标，不恢复独立 Arc 面板。**仅 Arc Swap、Bridge 不在本轮范围**；保留现有 Solana Swap。

客户端仓库：`FrankYan2023/benny-wallet-app`，`apps/wallet_client_flutter`，分支 `arc`。
后台仓库：`FrankYan2023/benny-wallet`，`apps/wallet_api`，分支 `arc`。

## 架构与边界

- 保留现有 Solana 派生路径、加密钱包格式和外部钱包行为；同一助记词独立派生 EVM `m/44'/60'/0'/0/0`。不转换 Solana 私钥，不迁移已有密钥。
- Flutter 的 ChainAdapter、账户、资产、交易模型继续作为协议边界。网络配置、RPC、金额精度和交易编码不进入 UI。
- 后台统一使用现有 Fastify、钱包会话、Supabase 与 FCM。新增 `/v1/arc-rpc`，由后台管理 RPC 提供商、超时和读请求切换。
- 私钥、助记词和签名留在手机。后台只接受已经签名的交易，并检查网络、签名人、钱包绑定和儿童模式；不存储原始已签名交易。
- 现有 Solana 登录会话绑定 EVM 地址时，需要该 EVM 地址的独立 EIP-191 所有权证明。随机挑战限时、单次消费，不能只凭客户端上报地址。
- “收款接口”包括余额、地址绑定、到账索引与通知；链上接收无需后台代签。已签名发送只尝试一次，超时按交易哈希查询，不能自动重发。

## 必须完成的验收目标

| 编号 | 目标 | 验收证据 |
|---|---|---|
| P01 | 主网配置与服务发现 | 核实官方链 ID、RPC、浏览器、USDC；客户端与后台网络不一致必须拒绝 |
| P02 | 后台 Arc RPC | 鉴权、方法白名单、参数/体积限制、超时、读请求切换；不接受用户提供上游地址 |
| P03 | 安全发送 | 手机签名 EIP-1559；后台验证签名人/网络/权限，先记录哈希；重复请求不再次广播 |
| P04 | 双链统一收发 UI | 明确网络、链图标、地址/二维码、余额不足和费用展示；Solana 回归 |
| P05 | 资产与总估值 | 单一 USDC 展示，原生 18 位与 ERC-20 6 位隔离；主网计价，测试网不计价；未知价格显示未计价 |
| P06 | 自定义代币云同步 | 按钱包、网络和合约隔离，链上核验元数据；另一设备恢复公开代币列表，不同步密钥 |
| P07 | 持久化历史 | 后台分页索引原生 USDC 与 ERC-20 Transfer；游标、去重、回填进度、收据/失败交易状态 |
| P08 | 到账通知 | 复用 FCM 设备注册；链字段、去重、重试、通知跳转；历史回填不轰炸通知 |
| P09 | 服务管理 | 上游凭据仅后台；配置、健康检查、部署/回滚说明；索引失败可恢复 |
| P10 | 签名准备 | EIP-191/EIP-712 与正确 WalletConnect namespace；全 DApp/WalletConnect UI 仍非本轮基础钱包验收前置条件 |
| P11 | 平台与安全 | Android 模拟器优先，静态检查/单元/集成测试；iOS 构建结果据实记录，不将环境阻塞写成通过 |
| P12 | 可追溯文档 | 前后端测试矩阵、变更日志、服务依赖、迁移和运行手册，区分实现/本地验证/部署/链上验收 |

## 当前已核实的服务

Solana 继续使用后台 Solana RPC/Helius（发送、增强历史、Webhook）、Jupiter（Swap）、CoinGecko（价格）；Arc 使用标准 EVM RPC、后台索引和 CoinGecko 合约映射价格。两链复用 Supabase 持久化、FCM 通知与现有钱包会话。Arc 不调用 Jupiter 或 Helius 的 Solana 接口。

## 主网资料与实际限制

2026-09-26 核实 [Arc RPC](https://docs.arc.io/arc/references/rpc-endpoints) 与 [合约地址](https://docs.arc.io/arc/references/contract-addresses)：mainnet `5042`，testnet `5042002`，USDC `0x3600000000000000000000000000000000000000`；主网浏览器 `https://explorer.arc.io`。费用文档中的测试网参数不能当作主网固定费率。

本机之前对 Circle 与 dRPC 主网节点的只读探测收到 HTTP 403。此事实不等于主网不存在，也不等于生产服务器已能访问；需要在部署环境验证链 ID、余额、估费、收据和日志。不得通过编造成功结果或真实用户资金来完成验收。
