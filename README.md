# benny-wallet-app

Benny Wallet is a non-custodial Solana wallet mobile client.

## Features

- Create and import Solana wallets
- On-device wallet storage and local transaction signing
- Non-custodial Solana wallet flows for Android, iOS, and Web
- PIN lock, biometric unlock, auto-lock, and secure clipboard handling
- Portfolio overview, token balances, receive, send, and transaction history
- Swap and token exchange flows
- Parent/child wallet monitoring and child mode restrictions
- BYC airdrop, check-in, and points views
- In-app notifications and support flow
